# 验收目录与认证文件、代理检查实施计划

**目标：** 让后续维护者能按固定清单复测，并明确区分实现情况与验收结果

**设计：** 复用 Manager、LiteLLM 和 Dashboard 的既有测试，用薄执行器归档命令及结果。真实账号只从外部路径按需读取，真实测试与模拟测试分开记录；不建设第二套业务接口

**范围：** 文件导入、代理延迟、相关回归和验收管理；OAuth 排除，生产发布与破坏性恢复不执行

## 执行与验证

- [ ] 验收执行器先写失败测试，再实现退出码分类和报告生成；用真实子进程验证成功、失败、跳过及未执行行为
- [ ] 调用生产 `file_identity` 校验外部认证文件；输出文件槽位及状态，不输出文件名或凭据；核对前后文件 hash 一致
- [ ] 获取已授权网站登录态，先预览一个文件；只有有效且不重复时提交，记录队列到最终状态，重复提交不能新增卡片；不触发 OAuth
- [ ] 复现代理页面错误，沿网站接口到 Manager 和 Clash 定位；若确认代码缺陷，先回归测试，再制作最小修复副本、补丁、验证记录与自包含回滚
- [ ] 执行 Manager、相关网关和前端回归，生成本轮报告，记录未完成项的原因和继续命令

## 成功标准

报告能追溯每项命令与证据，不把退出 0 中的跳过计为全通过，不把缺少登录或服务器权限解释为功能未实现。真实导入仅在后台最终可用状态得到验证后通过。代理延迟仅在接口与页面均出现真实测量值后算线上修复通过
